# 🎓 Student Management System

A full-stack Student Management System built using **React.js**, **Spring Boot**, and **MySQL**.  
This project allows users to manage student records with CRUD operations through a clean and responsive interface.

---

# 🚀 Features

✔️ Add Student  
✔️ Update Student  
✔️ Delete Student  
✔️ View Student List  
✔️ REST API Integration  
✔️ Responsive UI  
✔️ Full Stack Project

---

# 🛠️ Tech Stack

## Frontend
- React.js
- Axios
- CSS

## Backend
- Spring Boot
- Spring Data JPA
- MySQL

Student_Management_System

---

# ⚙️ Frontend Setup

## Navigate to frontend

```bash
cd frontend
```

## Install dependencies

```bash
npm install
```

## Run frontend

```bash
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

# ⚙️ Backend Setup

## Navigate to backend

```bash
cd college-managment
```

## Run Spring Boot project

```bash
./mvnw spring-boot:run
```

Backend runs on:

```bash
http://localhost:8081
```

# 🔗 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /students | Get all students |
| POST | /students | Add student |
| PUT | /students/{id} | Update student |
| DELETE | /students/{id} | Delete student |
